## 대응 자료

- 전체 대응: screen-manifest.json, asset-catalog.json, source-assets.json.
- 기본 설명: 게임/인물/역할 카드, 총알, 세피아 게임 매트, 직립 카드 더미.
- 체험: 양옆 실루엣, 둥근 나무 테이블, 원근 매트, 원근 카드 더미, 버린 카드 더미, 펼친 손패.
- 홈 및 공통: 나무/종이 질감, 테두리, BANG! 로고, 현상수배 포스터, 버튼 장식, 별/뒤로가기 SVG.
- 수정 가능한 문구는 data/dialogues.js의 실제 HTML 텍스트 데이터. 카드 자체 인쇄 문구는 원본 이미지.

## 남은 확인 사항

- 신규 화면 연결 순서와 클릭 분기: 사용자 확인 전까지 임의 연결하지 않음.
- 사용자 제공 Adobe Fonts 키트 xde7urj 연결: omnigothic 일반 400 / 세미볼드 600 사용. 오프라인일 때 시스템 폰트로 대체.
- 외곽 프레임은 기존 저해상도 PNG여서 3배수 참고 화면보다 선명도가 낮음.
- 그림자/선택 확대/가림 상태는 PNG의 정적 상태를 기준으로 구성. 복잡한 애니메이션은 후속 단계.
