# 펼치는 목차

## 동작

- 별을 STEP 1~3 제목에 놓거나 제목을 누르면 해당 STEP의 하위 항목만 펼칩니다. 본문은 아직 이동하지 않습니다.
- 하위 항목에 별을 놓거나 항목을 누르면 인트로 없이 해당 기존 학습 화면으로 이동합니다.
- 동시에 한 STEP만 펼쳐집니다. 같은 제목을 다시 누르면 접힙니다.
- 다른 STEP과 하단 바로가기는 부드럽게 아래로 이동합니다. 별의 연결선도 늘어나며, 스크롤하면 숨겨진 버튼까지 접근할 수 있습니다.
- 별을 상하 가장자리로 끌면 자동 스크롤합니다. 키보드 화살표로 위치를 고르고 Enter/Space로 선택할 수도 있습니다. 취소한 드래그는 이동하지 않습니다.
- STEP 4·5는 준비 중 안내를 유지합니다. 글자 굵기 400, 기존 그래픽과 닫기 슬라이드를 유지합니다.

## 파일

`learning-contents.js`는 목차 레이아웃과 별 선택/스크롤을 담당하고, `learning.js`는 기존 오버레이에 이를 연결합니다. `learning.css`에 펼침·이동 스타일을 추가하고 `index.html`에서 모듈을 로드합니다. `scripts/verify-contents.html`로 실제 브라우저 검증을 수행합니다. STEP 3 기존 검사도 새 목차 구조에 맞췄습니다.

작업 전 코드 백업은 `/tmp/bang-contents-before-20261022-093804.tar.gz`입니다. 시뮬레이션 코드와 데이터, 카드 이미지 원본은 수정하지 않습니다.

## 검증

390×844 브라우저에서 하위 목차 13개 연결, 실제 PointerEvent 별 드래그, 인트로 생략, 다른 STEP 접기, 닫힌 항목 포커스 제외, 하단 버튼 스크롤 접근, 드래그 취소, STEP 4 준비 안내, 키보드 선택, 글자 굵기 400, 닫기 슬라이드, 가로 넘침과 실행 오류 검사를 통과했습니다.

추가 검증: 별을 하단 가장자리로 끌 때 자동 스크롤되는 동작과 320px로 축소한 화면의 드래그 좌표 일치도 통과했습니다.

현재 위치 표시: 목차를 열 때는 현재 STEP 제목에 별을 표시하고, 그 STEP을 펼치면 현재 본문이 속한 소목차로 별을 이동합니다. 같은 소목차의 연속 프레임과 역할 상세 화면도 묶어 판별하며, 접으면 STEP 제목으로 돌아갑니다. 펼치기만 해서는 본문이 이동하지 않습니다.
