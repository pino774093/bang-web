기준 파일: wx8niTPbQU7HHrA4TL9RdL / Page 1 (0:1). Figma 원본은 읽기만 했습니다.

## 반영 범위

- 홈: 처음부터 배우기, 카드&규칙 찾기, 게임 시뮬레이션의 세 메뉴.
- STEP 목차: 최신 다섯 항목과 설명 중 열고 닫을 수 있는 공통 목차.
- STEP 1: 구성품, 인원별 역할 카드 구성, 개인 세팅, 전체 세팅의 Figma 전용 화면.
- STEP 2: 역할과 승리 조건, 역할 카드 탐색 및 상세 복귀.
- STEP 3: 전용 시작 화면과 카드 뽑기·사용·버리기 설명.
- STEP 4·5는 준비 중 안내만 표시합니다. 검색·필터·FAQ는 새로 만들지 않았습니다.
- 카드 메뉴는 기존 도감 및 상세 설명으로 연결해 기존 기능을 유지합니다.

## 시뮬레이션 보존

홈의 게임 시뮬레이션은 기존 5:229로 진입합니다. 기존 네 역할별 체험의 프레임, 연결, 카드 연출, 타이밍은 변경하지 않았습니다.
학습 화면은 learn: 접두사를 붙인 별도 프레임과 별도 DOM에서 표시합니다. 같은 Figma ID를 가진 기존 시뮬레이션 프레임을 덮어쓰지 않습니다.

interactions.js, screen-renderer.js, data/figma-flow.js, data/screens.js, data/dialogues.js, styles.css, screens.css의 SHA-256은 수정 전과 같습니다.
공통 app.js에는 학습용 화면 선택·타이머 시작/취소 분기만 추가했으며 기존 애니메이션 구현은 수정하지 않았습니다.

## 데이터와 재생성

- contexts.json: 읽기에 성공한 45개 프레임의 디자인 컨텍스트.
- frames.json: 학습 프레임의 문구와 실제 프로토타입 연결 요약.
- geometry.json: 별도로 확보한 일부 프레임의 읽기 전용 레이어 정보.
- asset-map.json: Figma 개별 에셋과 실제 로컬 파일의 대응.
- scripts/build-learning.py: 컨텍스트를 프로젝트의 HTML/CSS/JavaScript 방식으로 변환.
- data/learning-scenes.js: 런타임에서 표시할 HTML과 연결 데이터.
- learning.js, learning.css: 공통 학습 렌더링·목차·조작.
- fonts.js, fonts.css: 사용자 제공 Adobe Fonts 키트 xde7urj 및 공통 omnigothic 지정. 로드 제한 시간은 제공한 스크립트와 같은 3000ms이며 로드 후 문구를 다시 측정합니다. 홈·학습·도감·시뮬레이션 UI·검토 화면이 같은 폰트 지정을 사용합니다.

`python3 scripts/build-learning.py`로 재생성합니다. 내려받은 에셋이 있으면 네트워크 없이 재사용합니다.
현재 화면은 59개 상태를 공통 렌더러로 표시하며, 시작 타이틀 및 카드 배치 상태 일부는 자동으로 전환됩니다. 독립 HTML 페이지를 171개 만들지 않았습니다.
문구는 실제 HTML 텍스트로 표시하며, 이미지 내부의 인쇄 문구는 원본을 유지합니다.

Figma MCP의 Starter 사용량 제한 때문에 일부 STEP 2 프레임의 추가 디자인 컨텍스트는 읽지 못했습니다. 해당 프레임은 확인한 최신 문구·메타데이터와 기존 카드 배치를 재사용했습니다. 역할 탐색 및 상세는 확보한 최신 메타데이터의 위치를 반영했습니다.
