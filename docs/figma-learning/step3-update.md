작업 전 백업: 프로젝트 상위 폴더의 `bang-backup-step3-20261022-045147.tar.gz`.

## 변경 파일

- `step3-learning.js`: 턴 시작 판정, 타이밍 탭 4개, 주의사항 아코디언 6개. 카드 원본 재사용.
- `learning.js`: 학습 영역에만 신규 경로 등록, 기존 화면 사이 연결, STEP 전체/오버레이 목차 소주제 바로가기, 목차 열기 아이콘 통일. 기존 윌리 더 키드 문구는 HTML에서 교정.
- `learning.css`: 기존 양피지·목재·검정 설명창·빨간 버튼을 재사용하는 390×844 레이아웃.
- `index.html`: 신규 학습 모듈 로드 및 캐시 버전 갱신.
- `scripts/verify-step3.html`: 새 학습 흐름·탭·아코디언·목차·모바일 경계 검사.
- `scripts/verify-learning.html`: 기존 화면 회귀 검사에 목차 아이콘 검사 추가.

기존 PNG/SVG, Figma 추출 원본, STEP 4·5·카드 도감은 수정하지 않았습니다. 모든 UI 글자 굵기는 400으로 통일하며 색과 밑줄로 핵심을 강조합니다.

## 화면 연결

STEP 3 도입 → **기존 카드 뽑기** → **기존 카드 사용하기** → **기존 카드 버리기 2단계** → 추가 카드 사용 타이밍 → 추가 내 턴 주의사항 → STEP 4 준비 안내.

기존 Figma 프레임 사이에 신규 설명 화면을 삽입하지 않습니다. 원본 순서 `131:1182 → 139:236 → 139:249 → 139:265 → 139:351`을 유지합니다.

추가 설명의 상단은 타이밍/주의사항 두 소주제만 표시합니다. 턴 시작 판정 상세(`learn:turn-start`)는 타이밍의 턴 시작 탭에서 필요할 때 여는 보충 설명이며, 기본 진행에는 끼워 넣지 않습니다. 전체/오버레이 목차의 소주제 바로가기는 유지합니다.

## 규칙 확인

기준: [dV Games 공식 기본판 규칙, 4판](https://bang.dvgiochi.com/content/1/docs/01_bang_rules_EN.pdf), 인쇄 페이지 3·5~9·11.

사용자가 제공한 설명을 기준으로 검증하고 다음 예외를 짧게 보충했습니다.

- 맥주는 마지막 2명일 때 효과 없음. 상대 턴의 평상시 회복과 탈락 직전 대응 구분.
- 윌리 더 키드는 장착 카드가 아닌 캐릭터 능력. 볼캐닉의 횟수 예외도 사정거리 제한은 유지.
- 결투·인디언 대응으로 버리는 뱅!은 공격용 뱅! 1장 제한과 별개. 통·빗나감!을 사용하지 않음.
- 감옥보다 다이너마이트를 먼저 처리. 판정으로 공개한 카드는 손패가 되지 않음.

## 검증

Chrome의 390×844 iframe에서 STEP 3 연결·타이밍 4개·키보드 탭 전환·6개 규칙 펼치기·관련 화면·두 종류 목차 바로가기를 검사했습니다. 신규 화면 3개의 가로 넘침/하단 버튼 잘림과 이미지 로드를 검사했습니다. 타이밍 4개 모두 설명창 안에 맞으며, 긴 규칙 펼침은 설명창 내부에서 스크롤합니다.

STEP 3 전용 검사와 전체 학습 회귀 검사는 모두 PASS입니다. 전체 학습 화면 62개의 렌더링·이미지·가로 넘침, 기존 카드 도감과 시뮬레이션 진입·역할 선택도 통과했습니다. 보호 대상 8개 파일은 작업 시작 시점 SHA-256과 동일합니다: `app.js`, `screen-renderer.js`, `interactions.js`, `styles.css`, `screens.css`, `data/figma-flow.js`, `data/screens.js`, `data/dialogues.js`.

후속 수정: 카드 뽑기를 포함한 원본 프레임 순서를 먼저 진행한 뒤 추가 설명을 보도록 구성했습니다. 순서형 학습 설명창의 전체 영역(본문·여백·클릭 안내)을 같은 다음 프레임으로 연결했습니다. 탭·펼쳐보기와 역할 상세의 뒤로가기 기능은 유지합니다. 390×844 STEP 3 검증에 카드 뽑기 직접 이동, 설명창 여백의 실제 클릭 대상, 다음 연결, 400/600 계산 스타일 검사를 추가했고 PASS를 확인했습니다.

전체 STEP 목차와 오버레이 목차의 제목·항목·바로가기 글자는 별도 규칙으로 모두 400을 고정합니다. 학습 제목/버튼의 600 규칙보다 우선합니다.

최종 폰트 요청 반영: 모든 UI를 400으로 통일했습니다. 제목·버튼의 600 예외와 목차 전용 예외를 제거했습니다.
