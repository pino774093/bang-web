# 최신 로컬 Figma 읽기 검증

Figma MCP 대신 프로젝트에 있는 로컬 .fig 파일을 읽어 화면 흐름 구현에 사용했습니다. 원본 .fig 자체는 수정하지 않았습니다.

- 원본: `reference/최신로컬사본.fig`
- 내보내기 시각(한국): 2026-10-16 00:08:23
- 레이어: 2707개
- 최상위 프레임: 148개
- 유효한 인터랙션: 221개
- 내부 이미지: 52개

실제 연결 예시: 홈(5:4)의 게임 설명 시작 버튼(8:326)은 소개가 아니라 챕터 메뉴(47:2539, 이름 home)로 연결됩니다. 같은 이름의 프레임을 ID로 구별해야 합니다.

## 추출 파일

- frames.json: 프레임 ID/이름/크기/실제 문구
- connections.json: 트리거, 목적지 ID, 전환 시간/효과
- layers.json: 위치·크기·폰트·색상 등 레이어 정보
- summary.json: 원본 해시 및 검증 수치

삭제되었거나 유효하지 않은 목적지 연결은 런타임에서 제외했습니다. 실제 웹 런타임에는 147개 화면, 160개 클릭 동작, 52개 시간 전환을 반영했습니다. 네 역할은 각각의 Figma 원본 흐름으로 분기합니다. 재생성 방법은 `scripts/read-local-figma.cjs`, `scripts/match-local-frames.py`, `scripts/build-figma-flow.py`에 있습니다.

브라우저 확인: 홈 → 챕터 메뉴 → 소개 대사, 역할 선택 → 부관 전용 이야기, 카드 목록 → 카드 선택/목록 복귀, 브라우저 뒤로 가기를 로컬 Safari에서 확인했습니다. 카드 설명 문안은 후속 작업입니다.
