# BANG! 모바일 웹 설명서

## 최신 Figma 학습 화면 1차 반영

홈과 STEP 1~5 목차, STEP 1~3 학습 화면을 별도 학습 모듈로 추가했습니다. 게임 시뮬레이션 버튼은 기존 chapter 3 체험 화면으로 연결되며 시뮬레이션 내부는 보존합니다. 카드 메뉴는 기존 도감 기능을 유지하고, STEP 4·5 및 새 검색 기능은 구현하지 않았습니다.

확인이 필요한 두 연결과 변경 범위, 검증 방법은 [최신 Figma 학습 화면 기록](docs/figma-learning/README.md)을 참고하세요. 아래는 기존 구현과 원본 자료에 대한 설명입니다.

제공된 화면별 PNG 146장과 로컬 Figma 원본의 실제 연결 정보를 기준으로 구성한 BANG! 모바일 웹 설명서입니다. 화면은 개별 이미지 에셋, HTML 텍스트와 CSS로 표시합니다.
패키지 설치 없이 이 폴더에서 `npm run dev`를 실행하고 http://127.0.0.1:5180 을 엽니다.
종료는 Ctrl+C입니다. Node.js 없이 `python3 -m http.server 5180 --bind 127.0.0.1`도 가능합니다.

## 문구 수정

`index.html`의 실제 HTML 텍스트를 수정하면 됩니다. 이미지나 Figma를 다시 내보낼 필요가 없습니다.

- 홈 버튼: `<span class="button-label">게임 설명 시작 &gt;</span>` 및 카드 세부 설명 문구
- 소개 문장: `<p class="intro-copy">` 안의 각 `<span>`은 디자인상의 한 줄입니다.
- 소개 하단 표시: `<span class="intro-next-hint">&gt; 클릭!</span>`
- 글자 크기·간격·색상은 `styles.css`의 `.button-label`, `.intro-copy`, `.intro-next-hint`에서 조절합니다.
- 문장을 길게 변경하면 줄바꿈과 패널 안 여백을 브라우저에서 확인하세요.

## 에셋과 폰트

- 버튼의 빨간 면·검정 테두리·질감은 텍스트를 분리한 `rules-decoration.svg`, `cards-decoration.svg`입니다. 원본 경로는 보존했습니다.
- 소개 패널의 검정 면과 둥근 모서리는 CSS입니다. 문구는 선택·복사 가능한 HTML입니다.
- 뒤로가기 화살표는 글자가 아닌 아이콘으로 `back-vector.svg`에 유지했습니다.
- 로고와 현상수배 그림 안의 글씨는 원본 이미지의 일부로 유지했습니다.
- 원본 폰트는 버튼 `210 OmniGothic 040`, 소개 문구 `210 OmniGothic 030`입니다.
- 사용자가 제공한 Adobe Fonts 키트 `xde7urj`를 `fonts.js`에서 연결합니다. 실제 폰트 패밀리는 `omnigothic`이며 일반 400 / 세미볼드 600을 사용합니다. 인터넷 연결이 없거나 키트 로드가 실패하면 시스템 폰트로 표시됩니다.
- 정식 WOFF/WOFF2 파일을 확보하면 `@font-face`의 src에 url()을 추가해 적용합니다. 확인되지 않은 유료 폰트 파일을 배포하지 않습니다.
- 모든 에셋은 로컬에 저장되어 임시 Figma URL에 의존하지 않습니다. 기존 벡터/PNG는 비교·백업용으로 보관했습니다.

## 화면과 동작

- 화면은 390×844px을 기준으로 표시하고, 넓은 화면에서는 중앙에 모바일 비율을 유지합니다.
- 화면 연결과 클릭 위치는 함께 제공된 로컬 `.fig` 파일의 실제 프레임 ID 및 인터랙션을 읽어 적용했습니다. Figma MCP는 사용하지 않습니다.
- 홈의 ‘게임 설명 시작’은 원본 연결에 따라 챕터 메뉴로 이동합니다. 챕터/대사 진행, 네 역할 선택과 역할별 이야기, 카드 목록의 선택 및 상세 보기, 원본에 설정된 뒤로 가기·홈 이동을 지원합니다.
- 대화와 버튼은 터치와 클릭으로 조작합니다. 브라우저 방문 기록의 뒤로/앞으로 이동과 새로고침한 직접 링크도 지원합니다.
- 일반 화면 전환은 약 0.6초 디졸브입니다. chapter1 시작의 첫 두 전환도 명시적인 0.6초 크로스 디졸브로 처리합니다.
- 역할 카드 선택은 카드가 해당 슬롯에서 확대되며 뒤집히고, 돌아올 때 같은 슬롯로 역방향 이동해 뒷면으로 돌아갑니다. 선택한 역할의 작은 원본 카드는 확대 중 숨깁니다.
- 역할 카드와 카드 에셋은 개별 이미지를 사용하며, 글자와 조작 버튼은 HTML로 표시합니다. 카드별 설명과 ‘자주 헷갈리는 규칙’도 카드 화면에서 확인할 수 있습니다.
- 기존 포트폴리오 및 Figma 원본은 수정하지 않았습니다.

## 투명 배경 기준

버튼 외곽의 불필요한 흰 배경을 제거하며 검정 테두리·거친 질감·크기·위치·색상을 보존합니다.
현재 SVG는 내보내기 캔버스/상위 프레임 배경만 제거했습니다.
PNG 원본은 assets/originals/에 보관합니다. 이전 PNG 정리 스크립트는 복원용이며 현재 버튼에는 사용하지 않습니다.
향후 작업 지침은 AGENTS.md를 따릅니다.


## 전체 화면 디자인 미리보기

서버가 실행된 상태에서 http://127.0.0.1:5180/screens.html 을 여세요.
왼쪽 목록에서 화면을 선택하면 구현 화면과 원본 PNG를 나란히 확인할 수 있습니다.
수정 후에는 브라우저를 새로고침하거나 **변경 새로고침** 버튼을 누르세요.
**화면만 열기**는 비교 도구 없이 해당 390×844 화면만 엽니다.

- `reference/`의 전체 화면 PNG는 비교 페이지에서만 사용합니다. 실제 웹 화면은 개별 에셋, HTML 텍스트, CSS 패널로 구성합니다.
- `data/screens.js`: 화면별 에셋, 위치, 크기, 패널과 버튼 데이터.
- `data/dialogues.js`: 화면별 수정 가능한 대사/문구. 각 줄의 x/y/w/h는 원본 PNG에서 측정한 위치입니다.
- `screen-renderer.js`, `screens.css`: 공통 화면 구성 및 스타일. 원본 이미지의 비율과 투명도를 보존합니다.
- `assets/source/`: 제공된 104개 원본 파일의 중복을 제거한 102개 에셋. 원래 이름은 `docs/source-assets.json`에서 확인합니다.
- `assets/local-figma/`: 기존 로컬 파일에서 확보한 원본 이미지. Figma MCP에 접속하지 않습니다.
- `docs/screen-manifest.json`: 146개 화면 및 각 화면의 대응 에셋/문구 목록.
- `docs/asset-catalog.json`: 원본 파일명, 크기, 투명 영역을 정리한 에셋 목록.

화면 대응 및 실제 연결 추출 결과는 `docs/figma-local/`에서 확인할 수 있습니다. 브라우저 런타임 데이터는 `data/figma-flow.js`에 있습니다.

원본에 포함된 그림자는 유지하고, 별도 그림자가 필요한 카드에는 약 3px 이동/1px 흐림의 진한 그림자를 적용합니다. 버튼의 검정 테두리와 질감, 흰 글자/화살표는 유지합니다.

UI 폰트는 Adobe Fonts `omnigothic`으로 연결했습니다. 고해상도 프레임 장식은 현재 폴더에 없어 기존 프레임 PNG를 사용하므로 장식 선명도에 차이가 남습니다. 새로 제공되는 원본을 확보하면 교체할 수 있도록 분리했습니다.

## GitHub Pages 배포

이 프로젝트는 빌드 과정이 없는 정적 사이트입니다. `index.html`을 저장소 루트에 두고 Pages에서 바로 배포할 수 있으며, 이미지·스크립트 경로와 화면 이동은 저장소 하위 경로에서도 동작하도록 상대 경로와 해시 라우트를 사용합니다. `.nojekyll`도 포함되어 있습니다.

1. GitHub에서 새 저장소를 만들고, 이 프로젝트 폴더의 파일을 저장소 루트에 올립니다. GitHub Desktop으로 폴더를 추가한 뒤 커밋하고 `Publish repository`를 선택하면 됩니다.
2. 저장소의 **Settings → Pages**에서 **Build and deployment**를 `Deploy from a branch`로 설정합니다.
3. 브랜치는 `main`, 폴더는 `/(root)`로 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 Pages 설정에 표시되는 주소(`https://계정명.github.io/저장소명/`)를 엽니다. 휴대전화에서도 같은 주소로 접속하면 됩니다.

`.gitignore`는 macOS 메타데이터, 분석용 Python 환경, 웹사이트에서 사용하지 않는 녹화 영상과 `.fig` 파일을 제외합니다. 화면 비교 도구에서 쓰는 PNG 참고 이미지는 저장소에 포함됩니다. 로컬 미리보기는 계속 `npm run dev`로 실행합니다.
